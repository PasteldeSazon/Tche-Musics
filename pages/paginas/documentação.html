Bem-vindo à Documentação do Tche Musics!

Oi! Se você está lendo isso, provavelmente quer entender melhor o meu site sobre músicas gaúchas. Eu criei este espaço para compartilhar as músicas que eu amo, especialmente as do Rio Grande do Sul. Aqui, você vai encontrar informações sobre cantores, letras de músicas, biografias e muito mais. Vamos explorar tudo passo a passo, de forma simples e direta, como se estivéssemos conversando.

Estrutura do Site

O site é organizado de maneira fácil de navegar. Temos uma página inicial que dá uma visão geral, e depois várias seções dedicadas a diferentes temas. Aqui vai um resumo:

  • Página Inicial (index.html): O ponto de partida. Aqui você encontra links para todas as músicas principais e uma introdução ao tema gaúcho.

  • Páginas de Músicas: Cada música tem sua própria página HTML, com letra, informações sobre o cantor e talvez uma capa ou imagem relacionada.

  • Biografias: Uma pasta dedicada às histórias dos cantores gaúchos famosos, como Teixeirinha, Os Serranos e outros.

  • Páginas Extras: Temos seções sobre o Rio Grande do Sul, ferramentas usadas no site, código fonte e sobre nós.

Para navegar, use o menu no topo de cada página. É bem intuitivo!

Páginas Principais

Vamos falar um pouco sobre cada parte do site:

Músicas

As músicas são o coração do site. Cada uma tem uma página dedicada, onde você pode ler a letra completa, saber quem canta e um pouco sobre a história da música. Exemplos incluem "Tordilho Negro", "Querência Amada" e muitas outras clássicas do folclore gaúcho.

Biografias

Nesta seção, conto um pouco sobre a vida dos cantores. É como uma enciclopédia pessoal. Você encontra desde Teixeirinha até grupos como Os Mirins. Cada biografia tem detalhes interessantes sobre suas carreiras e contribuições para a música gaúcha.

Outras Páginas

  • Sobre Nós: Aqui eu me apresento e explico o motivo de ter criado o site.

  • Ferramentas Utilizadas: Uma lista das tecnologias e ferramentas que usei para construir o site, como HTML, CSS e Bootstrap.

  • Código do Site: Para quem quiser ver como tudo foi feito, mostro trechos do código fonte.

  • Todo Rio Grande do Sul: Uma página especial sobre o estado, com informações culturais e históricas.

Tecnologias Usadas

Eu não sou um expert em programação, mas consegui montar o site usando ferramentas básicas e acessíveis. Aqui vai o que usei:

  • HTML: A base de tudo. Usei para estruturar as páginas, criar títulos, parágrafos e links.

  • CSS: Para deixar tudo bonito. Criei estilos personalizados no arquivo "estilo.css" para cores, fontes e layouts.

  • Bootstrap: Uma biblioteca que ajuda a fazer designs responsivos, ou seja, que funcionam bem em celulares e computadores.

  • Imagens e Capas: Fotos e capas das músicas estão na pasta "imagens capas". Elas ajudam a ilustrar o conteúdo.

Se você quiser aprender mais sobre essas ferramentas, há links na página de "Ferramentas Utilizadas".

Como Manter ou Atualizar o Site

Como o site é simples, é fácil de atualizar. Aqui vão algumas dicas:

  • Adicionar uma Nova Música: Crie um novo arquivo HTML na raiz, copie a estrutura de uma música existente e personalize com a letra e informações.

  • Editar Biografias: Vá na pasta "biografias" e edite os arquivos HTML correspondentes.

  • Mudar Estilos: Abra o "estilo.css" e ajuste as cores ou layouts. Use as recomendações no arquivo "recomendações de uso das cores.txt" para manter a harmonia.

  • Testar: Sempre abra as páginas no navegador para ver se tudo está funcionando.

Se você encontrar erros ou quiser sugerir melhorias, entre em contato comigo pelos dados no rodapé.
